What JavaScript is doing:

It reads the number from the HTML input box, performs calculations, then writes the answers into the result cards.

For example, squaring uses number * number, while the square root uses Math.sqrt(number).

Angles, sine and cosine

Enter an angle in degrees. JavaScript converts it into radians before calculating its sine and cosine.

The conversion:

Degrees are converted into radians using:

radians = degrees × π ÷ 180

JavaScript then uses Math.sin(), Math.cos() and Math.tan().
