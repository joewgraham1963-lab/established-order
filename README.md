# Established Order

A small beginner HTML project created entirely on a cheap Android phone.

## What this project is

This website is intended to help ordinary people make their first working HTML project on a phone.

## What I learned

Today I:

- created a GitHub account
- created a private repository
- uploaded `index.html` and `battleship-grey.html`
- connected the repository to Netlify
- enabled automatic deployment
- edited the website on GitHub
- committed the change
- watched Netlify update the live site automatically

## The important workflow

1. Open `index.html` on GitHub.
2. Choose **Edit file**.
3. Make the change.
4. Commit directly to the `main` branch.
5. Wait for Netlify to redeploy the site.

No ZIP file is required once GitHub and Netlify are connected.

## Current status

This is still a practice project. The process is not always easy, especially on Android, but the site is working and can now be updated through GitHub.
