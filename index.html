What this project is

This website is for ordinary people who want to make their first working HTML project on a phone.

What I learned

I created a GitHub repository, added my website files, connected GitHub to Netlify, and made a live change without using a ZIP file.

The basic workflow

  1. Open index.html on GitHub.
  2. Edit the file.
  3. Commit the change to the main branch.
  4. Wait for Netlify to update the live site.
