HTML Playground

HTML stands for HyperText Markup Language. q It gives a webpage its basic structure and content.

HTML is made from elements. An element usually has an opening tag, some content, and a closing tag.

For example:

<p>This is a paragraph.</p>

Here, <p> begins the paragraph and </p> ends it.

Some HTML elements can also contain attributes. Attributes give the element extra information.

For example:

<a href="https://example.com">Visit a website</a>

The href attribute tells the browser where the link should go.

A basic webpage usually contains:

<html> — the whole webpage
<head> — information about the page
<body> — the visible content
<h1> — a main heading
<p> — a paragraph
<a> — a link
<img> — an image

The file called index.html is normally the main page a web server looks for when somebody visits a website.

HTML does not usually control how the page looks or behaves. CSS controls appearance, while JavaScript controls behaviour.

CSS stands for Cascading Style Sheets. It controls how a webpage looks.

HTML provides the structure of a page. CSS changes the appearance of that structure.

For example:

p { color: red; }

This tells the browser to make all paragraph text red.

CSS rules are usually made from three parts:

Selector — what you want to style
Property — what you want to change
Value — what you want to change it to

In this example:

body { background: #848484; }

body is the selector.
background is the property.
#848484 is the value.

CSS can control things such as:

colours
fonts
text size
spacing
borders
rounded corners
shadows
positioning
page layout

For example:

border-radius: 18px;

gives an element rounded corners.

CSS can also create gradients.

For example:

background: radial-gradient(circle, #666666, #444444);

This creates a circular fade from one shade of grey to another.

CSS does not normally make the page do anything. It controls appearance.

HTML gives the page structure.
CSS gives it style.
JavaScript gives it behaviour.

JavaScript is a programming language that controls how a webpage behaves.

HTML provides the structure.
CSS controls the appearance.
JavaScript lets the page respond, calculate, change and move.

For example:

const number = 5;

This creates a variable called number and gives it the value 5.

JavaScript can also perform calculations:

const answer = 5 + 3;

The variable answer will now contain the value 8.

A function is a reusable piece of JavaScript that performs a task.

For example:

function sayHello() {
  alert("Hello");
}

When that function is called, the browser displays a message.

JavaScript can also react when somebody presses a button.

<button onclick="sayHello()">Press me</button>

The onclick part tells the browser to run the sayHello() function when the button is pressed.

JavaScript can store groups of things in an array.

For example:

const words = ["kettle", "Moon", "biscuit"];

This is the same basic idea used by the Random Absurd Message Generator and Random Insult Generator on this website.

JavaScript can choose something randomly using:

Math.random()

It can also find something already on the webpage and change it.

For example:

document.getElementById("message").textContent = "Hello";

This finds the HTML element whose id is message and changes the words displayed inside it.

JavaScript can therefore be used for things such as:

clocks
calculators
buttons
games
animations
random generators
changing colours
displaying live information

Dickinson's MK1 uses JavaScript to calculate the time and the positions of the Sun and Moon, move the clock hands, update the date, and animate the sweeping second hand.
