How webpages work

A basic webpage is built from three main ingredients: HTML provides the structure, CSS controls how it looks, and JavaScript controls much of what it does. The buttons below reveal a little more detail without sending you elsewhere.

HTML stands for HyperText Markup Language. It gives a webpage its basic structure and content. Elements such as <h1>, <p>, <a> and <img> tell the browser what each part of the page is.

The file called index.html is normally the main page a web server looks for when somebody visits a website.

CSS stands for Cascading Style Sheets. It controls appearance: colours, fonts, spacing, borders, rounded corners, shadows, positioning and layout. For example, body { background: #848484; } makes the page background battleship grey, because apparently civilisation has finally found its purpose.

JavaScript is a programming language used to make webpages respond, calculate, change and move. It can run clocks, calculators, animations, games and random generators. Functions perform reusable tasks, arrays can store groups of things, and Math.random() can select one at random.

Dickinson's MK1 uses JavaScript to calculate time and celestial positions, update the display and animate the clock.

Start here

To make the simplest possible website, create a file called index.html, add some HTML, then open it in a browser. From there you can make the browser battleship grey, learn how internet colour codes work, or enter the JavaScript Maths Laboratory.

Nobody remembers every HTML element. That is why references exist. The MDN HTML Reference is considerably more useful than pretending to remember the lot.
